Le texte et les liens

Une page Web peut contenir plusieurs paragraphes. Chaque paragraphe développe une idée.

Le contenu d’une page doit être lisible. Les titres aident à retrouver une information.

Insister sur un mot peut changer le sens d’une phrase. La balise i peut distinguer un mot étranger comme browser.

Un titre bien choisi aide le lecteur à trouver ce qu’il cherche.
